# Quiz Bot для Telegram

Інтелектуальний Telegram бот для створення та проходження квізів з використанням AI.

## Опис проекту

Quiz Bot - це автоматизована система для генерації та проходження тестових завдань через Telegram. Бот використовує штучний інтелект для створення квізів на різні теми та зберігає результати в базі даних.

## Основні функції

- 🤖 Автоматична генерація квізів за допомогою AI (g4f) **українською мовою**
- 📊 Збереження квізів та результатів у SQLite базі даних
- 👥 Система ролей: адміністратори та звичайні користувачі
- 🔐 Супер-адміністратор з можливістю призначати інших адмінів
- 👤 Автоматична реєстрація користувачів при першому запуску
- 📝 Інтерактивне проходження тестів
- 📈 Підрахунок балів та відображення результатів
- 🗑️ Управління квізами (створення/видалення)

## Повний setup бота (з нуля)

### 1) Передумови

- Python **3.10+** (рекомендовано)
- `pip`
- Telegram акаунт

Перевірка:

```bash
python --version
pip --version
```

### 2) Клонування проєкту

```bash
git clone <repository-url>
cd quiz_bot
```

### 3) Створення та активація віртуального оточення

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4) Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 5) Налаштування `.env`

Створіть `.env` на основі шаблону:

**Windows (PowerShell):**
```powershell
Copy-Item .env.example .env
```

**Linux / macOS:**
```bash
cp .env.example .env
```

Заповніть значення:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=your_telegram_admin_id_here
```

#### Де взяти значення:
- `TELEGRAM_BOT_TOKEN`: створіть бота через [@BotFather](https://t.me/botfather) (`/newbot`).
- `ADMIN_ID`: ваш Telegram user ID (наприклад через [@userinfobot](https://t.me/userinfobot)).

### 6) Ініціалізація бази даних

```bash
python -m scripts.init_db
```

### 7) (Опційно) Заповнення БД тестовими квізами

```bash
python -m scripts.add_manual
```

### 8) Запуск бота

```bash
python main.py
```

Після запуску відкрийте бота в Telegram і надішліть `/start`.

### 9) Швидка перевірка після запуску

1. `/start` — реєстрація користувача.
2. `/list` — перегляд доступних квізів.
3. Для адміністратора: `/new_quiz`, `/users`, `/delete_quiz [id]`.

### 10) Типові проблеми

- **`TELEGRAM_BOT_TOKEN not found in .env file`**  
  Перевірте, що `.env` існує в корені проєкту і містить коректний токен.
- **`ADMIN_ID not found in .env file`**  
  Вкажіть числовий Telegram ID без лапок.
- **Помилки імпортів у scripts**  
  Запускайте скрипти як модулі: `python -m scripts.init_db` / `python -m scripts.add_manual`.

## Використання бота

### Команди користувача:
- `/start` - Запуск бота та автоматична реєстрація
- `/list` - Перегляд доступних квізів
- `[ID квізу]` - Початок проходження квізу (введіть номер)

### Команди адміністратора:
- `/new_quiz` - Генерація нового квізу за допомогою AI (українською мовою)
- `/add_admin [user_id]` - Призначити користувача адміністратором
- `/remove_admin [user_id]` - Зняти права адміністратора з користувача
- `/delete_quiz [quiz_id]` - Видалити квіз з бази даних
- `/users` - Перегляд всіх зареєстрованих користувачів та їх ролей

### Процес проходження квізу:
1. Оберіть квіз зі списку (`/list`)
2. Введіть ID квізу
3. Відповідайте на питання використовуючи кнопки
4. Отримайте результат по завершенню

## Система ролей

### Типи користувачів:

#### 👤 Звичайний користувач
- Автоматично реєструється при `/start`
- Може переглядати список квізів (`/list`)
- Може проходити квізи
- **Не має доступу** до створення/видалення квізів

#### 👑 Адміністратор
- Усі права звичайного користувача
- Може створювати квізи через AI (`/new_quiz`)
- Може видаляти квізи (`/delete_quiz`)
- Може переглядати список користувачів (`/users`)

#### 🔱 Супер-адміністратор
- Визначається в `.env` файлі через `ADMIN_ID`
- Усі права адміністратора
- Може призначати інших адмінів (`/add_admin`)
- Може знімати права адміна (`/remove_admin`)
- **Не може бути видалений** з адмінів

### Як призначити адміністратора:
1. Користувач надсилає `/start` боту (автоматична реєстрація)
2. Користувач повідомляє свій Telegram ID супер-адміну
3. Супер-адмін виконує: `/add_admin [user_id]`
4. Користувач отримує права адміністратора

## Технології

- **Python 3.8+** - основна мова програмування
- **aiogram 3.4** - фреймворк для Telegram ботів
- **g4f** - безкоштовна AI генерація контенту
- **SQLite3** - локальна база даних
- **python-dotenv** - управління змінними середовища

## База даних

Структура таблиць:
- `users` - інформація про користувачів (user_id PRIMARY KEY, role TEXT: 'user' або 'admin')
- `quizzes` - список квізів (quiz_id, title)
- `questions` - питання квізів (question_id, quiz_id, question_text)
- `options` - варіанти відповідей (option_id, question_id, option_text, is_correct)
- `user_results` - результати проходження квізів (user_id, quiz_id, score)
