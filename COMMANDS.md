# Команди Quiz Bot

## 👤 Команди для всіх користувачів

| Команда | Опис |
|---------|------|
| `/start` | Запустити бота та зареєструватися |
| `/list` | Переглянути доступні квізи |
| `[число]` | Почати квіз (введіть ID квізу) |

## 👑 Команди для адміністраторів

| Команда | Опис | Приклад |
|---------|------|---------|
| `/new_quiz` | Створити новий квіз через AI | `/new_quiz` → введіть тему |
| `/delete_quiz [id]` | Видалити квіз | `/delete_quiz 5` |
| `/users` | Список всіх користувачів | `/users` |

## 🔱 Команди для супер-адміністратора

| Команда | Опис | Приклад |
|---------|------|---------|
| `/add_admin [user_id]` | Призначити адміністратора | `/add_admin 123456789` |
| `/remove_admin [user_id]` | Зняти права адміна | `/remove_admin 123456789` |

## Примітки

- Супер-адміністратор визначається в `.env` файлі через `ADMIN_ID`
- Супер-адміністратор не може бути видалений
- Нові користувачі автоматично реєструються з роллю 'user' при `/start`
- Всі повідомлення та квізи українською мовою
